# Neon Rift — Dodge Protocol v2
Open `index.html` in a modern browser. No build system or external libraries are required.

Structure:
- index.html
- css/style.css
- js/main.js
- js/game.js
- js/input.js
- js/attacks.js
- js/save.js
- assets/

Implemented as a functional original dodge-battle game: real canvas game loop, keyboard/touch input, attack lifecycle, 18 attack variants, HP/i-frames, score/time, escalating difficulty, settings, local records, pause/restart, fullscreen, responsive arena, particles, warnings, practice/survival/challenge/endless modes.

The project deliberately uses original names and visuals and contains no copied game assets.
